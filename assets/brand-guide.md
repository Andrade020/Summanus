# Summanus — identidade visual

**Ideia:** um clarão no centro de uma órbita. [Summanus](https://ora.ox.ac.uk/objects/uuid:0a487637-5cef-4436-b58e-455f84c0331e) é associado ao trovão noturno na tradição romana; o contraste entre o fundo escuro e o núcleo coral representa uma resposta que surge no próprio computador. A órbita sugere exploração.

| Papel | Cor |
|---|---|
| Fundo | `#0E111E` |
| Painel | `#131727` |
| Superfície | `#1B2034` |
| Coral, ação principal | `#FF967B` |
| Lilás, destaque | `#AB9CFF` |
| Menta, estado pronto | `#6EDABE` |
| Texto | `#F4F1F7` |

O [símbolo](summanus-mark.svg) é vetorial para uso em tamanhos pequenos. A [ilustração](summanus-glow.png) aparece na tela inicial e no ícone da janela. Botões e cartões usam cantos arredondados e contraste alto; a tipografia principal usa Segoe UI no Windows.
